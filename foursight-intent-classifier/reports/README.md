# reports/

Everything here is generated by the scripts in `scripts/`; nothing is hand-edited.

| path | produced by | content |
|---|---|---|
| `eda.md`, `eda.json` | `run_eda.py` | dataset statistics, duplicates / label conflicts, leakage check, lexical cues, design implications |
| `comparison.md`, `results/comparison.json` | `compare_candidates.py` | every candidate (baselines + fine-tuned encoders) on the same grouped CV, bootstrap CIs, ensembles, per-rule ablation, CPU latency |
| `results/final_selection.json` | `select_final.py` | the pre-stated selection policy applied to the comparison; the chosen configuration and why |
| `results/baselines_grouped.json`, `results/baselines_stratified.json`, `results/protocol_comparison.json` | `run_baselines.py` | full TF-IDF / embedding grids under both validation protocols and the leakage inflation per config |
| `results/transformer_<name>.json`, `results/oof_logits_<name>.npy` | `run_experiments.py` | per-fold curves, best epochs, pooled out-of-fold metrics and logits for each fine-tuned encoder |
| `results/analysis_<name>.json`, `error_analysis_<name>.md`, `results/oof_predictions_<name>.csv` | `analyze_results.py` | calibration (temperature, ECE, reliability), review-flag policy (deployment + cross-fitted), risk-coverage, rule ablation, categorised errors with examples, row-level OOF predictions |
| `results/logit_bias_study.json` | `study_logit_bias.py` | negative result: cross-fitted per-class logit bias |
| `results/latency.json` | `compare_candidates.py --latency` | CPU inference latency / fp32 size per base model (measured once, reused) |
| `results/score_py_oof_<name>.{txt,json}`, `results/score_py_folds_<name>.json`, `validation/` | `score_oof.py` | the **official scorer** run on out-of-fold validation files (pooled and per fold) |
| `results/submission_summary.json`, `test_predictions_with_confidence.csv` | `generate_submission.py` | submission validation summary; per-row confidence / margin / needs_review metadata for the test set |
| `figures/` | all of the above + `make_figures.py` | class distribution, cue heat-map, confusion matrices, reliability diagrams, risk-coverage curves, training curves, candidate comparison |
| `links.json` | hand-maintained | GitHub / Hugging Face / W&B links; `NOT PUBLISHED` until an authorised upload happens |
| `exp_*.log`, `baselines_*.log` | shell | raw training logs |

A chronological narrative of the experiments is in `docs/experiment_log.md`.

Validation protocol for every number: `StratifiedGroupKFold(n_splits=5, seed=42)` grouped on
normalised question text; metrics are pooled over the five out-of-fold predictions.

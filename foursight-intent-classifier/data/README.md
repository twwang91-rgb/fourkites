# data/

The challenge data is **confidential** and is intentionally not committed.

Place the files from the candidate package here before running anything:

```
data/train.csv              # 1,904 rows: id, question, intent
data/test.csv               # 566 rows:   id, question
data/labels.json            # closed label set + training distribution
data/sample_submission.csv  # submission format example
data/schema.json            # submission schema
```
